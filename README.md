# Blockage

A comprehensive Pi-Hole blocklist compiler that aggregates blocklists from multiple sources across the internet, deduplicates all domains, and creates one unified blocklist file containing only unique domains.

## Features

- **Multi-source aggregation**: Compiles blocklists from 20+ popular sources
- **Complete deduplication**: Ensures no duplicate domains in the final output
- **Domain validation**: Validates all domains before inclusion
- **Multiple format support**: Handles various blocklist formats (hosts files, domain lists, AdBlock format)
- **Comprehensive logging**: Detailed logging of the compilation process
- **Configurable sources**: Easy to add/remove sources via JSON configuration
- **Performance optimized**: Efficient processing of large datasets
- **Error resilient**: Continues processing even if some sources fail

## Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the compiler:**
   ```bash
   python blocklist_compiler.py
   ```

3. **Use the generated blocklist:**
   - The unified blocklist will be saved as `unified_blocklist.txt`
   - Import this file into your Pi-Hole as a custom blocklist

## Usage

### Basic Usage
```bash
python blocklist_compiler.py
```

### Custom Output File
```bash
python blocklist_compiler.py -o my_blocklist.txt
```

### Custom Configuration
```bash
python blocklist_compiler.py -c my_sources.json -o my_blocklist.txt
```

### Command Line Options
- `-o, --output`: Specify output file name (default: unified_blocklist.txt)
- `-c, --config`: Specify configuration file (default: blocklist_sources.json)

## Configuration

The `blocklist_sources.json` file contains all source configurations. You can:

- Enable/disable sources by setting `"enabled": true/false`
- Add new sources by adding entries to the `sources` array
- Modify settings in the `settings` section

### Adding New Sources

Add new sources to the configuration file:

```json
{
  "name": "My Custom Blocklist",
  "url": "https://example.com/blocklist.txt",
  "description": "Description of the blocklist",
  "enabled": true
}
```

## Output Format

The generated blocklist contains:
- Header with metadata and generation timestamp
- One domain per line
- Sorted alphabetically for consistency
- No duplicates guaranteed

Example output:
```
# Unified Pi-Hole Blocklist
# Generated by Blockage Pi-Hole Blocklist Compiler
# Total unique domains: 1234567
# Last updated: 2024-01-15 10:30:45 UTC
# https://github.com/greyfory/Blockage
#
0-0-1-rx.com
0-0-6-rx.com
000-dating.com
...
```

## Logging

The compiler generates detailed logs in `blocklist_compiler.log` including:
- Processing status for each source
- Domain extraction statistics
- Error messages for failed sources
- Final compilation statistics

## Performance

- Processes 20+ sources in typically 2-5 minutes
- Handles millions of domains efficiently
- Memory usage optimized with set-based deduplication
- Respectful delays between requests to avoid overwhelming servers

## Use with Pi-Hole

1. Run the compiler to generate `unified_blocklist.txt`
2. In Pi-Hole admin interface:
   - Go to Group Management → Adlists
   - Add new adlist with the file URL or upload the file
   - Update gravity to apply the new blocklist

## Automation

For automated updates, you can:
1. Set up a cron job to run the compiler regularly
2. Use the included GitHub Actions workflow (if enabled)
3. Host the output file and use it as a remote blocklist in Pi-Hole
